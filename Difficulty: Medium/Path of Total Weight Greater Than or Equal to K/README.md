<h2><a href="https://www.geeksforgeeks.org/problems/path-of-greater-than-equal-to-k-length1034/1">Path of Total Weight Greater Than or Equal to K</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given an undirected weighted graph with <strong>V</strong> vertices numbered from<strong> 0</strong> to <strong>V - 1</strong> and an integer <strong>k</strong>, find if there exists a simple path starting from the source vertex <strong>0</strong> such that the total weight of the path is greater than or equal to <strong>k</strong>.</span></p>
<p><span style="font-size: 14pt;">A simple path is a path that does not contain repeated vertices. Return true if such a path exists; otherwise, return false.</span></p>
<p><span style="font-size: 18px;"><strong>Example 1:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>V = 5, edges[][] = [[0, 1, 4], [0, 2, 8], [1, 4, 6], [2, 3, 2], [4, 3, 10]], k = 8<strong><br>Output: </strong>true<strong><br></strong></span><span style="font-size: 18px;"><strong><span style="font-size: 14pt;">Explanation: </span></strong><span style="font-size: 14pt;">One possible simple path is 0 -&gt; 1 -&gt; 4. The total path weight is 4 + 6 = 10, which is greater than or equal to k = 8.</span><strong><br><span style="font-size: 14pt;"><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/929819/Web/Other/blobid0_1781775355.webp" width="326" height="265"></span><br></strong></span></pre>
<pre><span style="font-size: 14pt;"><strong>Input</strong>: V = 4 , edges[][] = [[0, 1, 5], [1, 2, 1], [2, 3, 1]], k = 8
<strong>Output:</strong> false
<strong>Explanation</strong>: There exists no path which has a distance of 8 or more.</span></pre>
