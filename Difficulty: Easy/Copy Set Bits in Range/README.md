<h2><a href="https://www.geeksforgeeks.org/problems/copy-set-bits-in-range0623/1">Copy Set Bits in Range</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given two integers <strong>x </strong>and <strong>y</strong>, and two integers <strong>l </strong>and <strong>r </strong>representing a range of bit positions (inclusive), copy every set bit (1) from y to x for all positions between l and r. </span><span style="font-size: 18px;">Return the modified value of x. </span><span style="font-size: 18px;">Note: Bit positions are numbered from right to left, starting from 1.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> x = 44, y = 3, l = 1,  r = 5
<strong>Output: </strong>47 <br><strong>Explanation:</strong> Binary representation of 44 and 3 is 1011<span style="text-decoration: underline;">00</span> and 0000<strong>11</strong>. So in the range 1 to 5 there are two set bits of 3 (1st &amp; 2nd position). If those are set in 44 it will become 1011<span style="text-decoration: underline;"><strong>11</strong></span> which is 47.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> x = 16, y = 2, l = 1,  r = 3
<strong>Output:</strong> 18
<strong>Explanation:</strong> Binary representation of 16 and 2 is 100<span style="text-decoration: underline;">00</span> and <strong>10</strong>. If the mentioned conditions are applied then 16 will become 100<span style="text-decoration: underline;"><strong>10</strong></span> which is 18.</span></pre>
